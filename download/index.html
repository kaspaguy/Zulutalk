Installing

  1. Download the APK on your phone and open it.
  2. If Android asks, allow your browser to install unknown apps. This setting is under Settings → Apps → Special app access → Install unknown apps.
  3. Tap Install, then open ZuluTalk and add your SIP account, or open the setup link your provider gave you.

ZuluTalk is not in the Google Play Store yet. Updates install over the previous version, because every release is signed with the same key.

iPhone

There is no ZuluTalk for iPhone. Belledonne Communications publishes Linphone for iPhone on the App Store.
